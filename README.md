# Yano Coffee — موقع ثابت أبيض + برتقالي (HTML/CSS/JS فقط)

مفيش Node ولا سيرفر ولا قاعدة بيانات ولا fetch لأي ملف. افتح `index.html` بالدبل كليك أو ارفع الفولدر كما هو على أي استضافة.

## المنيو
المنيو موجود جوه `menu.html` كـ HTML عادي بين السطرين:
`<!-- ===== MENU START ... ===== -->` و `<!-- ===== MENU END ===== -->`
- استبدل اللي بينهم بملف المنيو بتاعك (الـ nav والفوتر والتصميم حوالين المنيو يفضلوا زي ما هم).
- لو عايز الفلاتر والبحث يفضلوا شغالين مع الـ HTML بتاعك: خلّي كل قسم `<section class="sec" data-cat="id" data-title-en="..." data-title-ar="...">` وكل صنف `<article class="item">` فيه `<h3>` للاسم. من غير كده الصفحة بتعرض الـ HTML بتاعك زي ما هو.
- الأرقام في الصفحة الرئيسية («95 صنف»، «من 20 جنيه»، أسعار الكروت) مكتوبة يدوي في `index.html`، عدّلها لو الأسعار اتغيرت.
